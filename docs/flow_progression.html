Hidden-Space Flow Drafter — Four Generations

All four predict K=4 future hidden states for a frozen Qwen3.5-0.8B, decode them with the frozen LM head, and the backbone verifies. They differ only in how each draft position gets the information it needs. The deep positions (3–4) are the battleground: acc@1 is ~0.96 everywhere; the gap is entirely in later positions, and it's a conditioning problem — does a position know the tokens before it?

Frozen backbone / LM head Context hidden (KV) Flow velocity net Predicted hidden Token feedback Markov logit-bias

① Hidden flow (stage1–4, the original)

All K hidden states predicted in parallel by integrating a flow velocity field (delta-init, 1–2 Euler steps), conditioned on context only. No position sees the others' tokens → deep positions guess blind.
greedy 2.68 · acc@4 0.45 · live 0.96×

② Reweight (same net, deep-position loss)

Identical architecture to ①. Only the loss changes: CE upweighted 4× on position 4, flatter accept weighting. Tries to emphasize deep positions — but can't add information they don't have.
greedy 2.89 · acc@4 0.45 · live 0.99×deep pos flat (stem helped, code hurt)

③ EAGLE (causal token feedback)

Drops the flow. One shared net runs autoregressively: each step takes the previous predicted hidden + the embedding of the token it just decoded. Full causal feedback — K sequential passes.
greedy 3.21 · acc@4 0.57 · live 1.02×

④ Markov flow (flow + cheap token feedback)

Keeps the parallel flow (one pass, ① unchanged). Adds a rank-256 Markov head: a token→logit bias W₂(W₁[prevₜ]) applied left-to-right over the block at decode time — injecting the previous-token info without extra flow passes.
greedy 2.93 · acc@4 0.47 · live 1.003×stem acc@4 0.50→0.74

The arc: deep-position acceptance is a conditioning problem, not capacity/data/loss. ① proves parallel flow plateaus; ② proves you can't reweight your way to information a position doesn't have; ③ proves full causal token feedback fixes it (but abandons flow and pays K passes); ④ keeps the flow and recovers most of the gain with a cheap rank-256 logit-bias correction — the first hidden-flow drafter to cross 1× live, and it beats EAGLE-level deep accept on stem. Open issue: ④ regresses on code (hardest/most-diverse domain), the same place ② hurt — the Markov correction helps where token→token transitions are learnable and can mislead where they aren't.
